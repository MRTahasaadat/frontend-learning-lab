# JavaScript | منطق و پویایی صفحات وب

این بخش به یادگیری و تمرین برنامه‌نویسی و پویاسازی وب با زبان **JavaScript** اختصاص دارد.

---

## هدف

هدف از ایجاد این بخش، کسب توانایی در افزودن منطق، رفتار و تعامل‌پذیری به صفحات وب است. اگر HTML اسکلت صفحه و CSS لباس و ظاهر آن باشد، جاوا اسکریپت **«سیستم عصبی و مغز»** آن است. در این پوشه تمرکز بر یادگیری اصول برنامه‌نویسی سمت کاربر، حل مسئله و زنده کردن صفحات ثابت است.

---

## مفاهیم و مباحث کلیدی

در این بخش، تمرین‌ها و نمونه‌کارهای مرتبط با موارد زیر قرار می‌گیرد:

1.**مبانی زبان (Basics):**
   - تعریف متغیرها (`let`, `const`) و آشنایی با انواع داده‌ها (Strings, Numbers, Booleans, arrays, objects)
   - ساختارهای کنترلی: دستورات شرطی (`if/else`, `switch`) و حلقه‌ها (`for`, `while`)

2.**توابع و اسکریپت‌نویسی پیشرفته (Functions & ES6+):**
   - تعریف و فراخوانی توابع (Function Declarations & Arrow Functions)
   - متدهای کاربردی آرایه‌ها و آبجکت‌ها (`map`, `filter`, `reduce`)
   - ویژگی‌های مدرن جاوا اسکریپت (Destructuring, Template Literals, Spread/Rest operators)

3.**تعامل با صفحه و مدیریت رویدادها (DOM Manipulation & Events):**
   - انتخاب و دستکاری عناصر صفحه (`document.querySelector`, innerHTML و...)
   - گوش دادن به رویدادهای کاربر مانند کلیک، تایپ، اسکرول و ارسال فرم (`addEventListener`)

4.**برنامه‌نویسی ناهمگام (Asynchronous JavaScript):**
   - درک مفهوم کدنویسی ناهمگام و چرخه رویداد (Event Loop)
   - کار با Promiseها و دستورات مدرن `async/await`
   - دریافت و ارسال داده از سرور با استفاده از `fetch API` (ارتباط با سرورهای خارجی)

5.**پروژه‌های تعاملی کوچک (Mini-projects):**
   - پیاده‌سازی ابزارهای کاربردی مانند ماشین‌حساب، لیست کارها (Todo List)، اسلایدر تصاویر، فرم‌های اعتبارسنجی و...
