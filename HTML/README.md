# HTML | اسکلت و ساختار وب

این بخش به یادگیری و تمرین زبان نشه‌گذاری **HTML5** (HyperText Markup Language) اختصاص دارد.

---

## هدف

هدف از ایجاد این بخش، تسلط بر نحوه ساختاردهی اصولی و معنایی صفحات وب است. تمام وب‌سایت‌هایی که در اینترنت مشاهده می‌کنید، پایه و اساس ساختار خود را از HTML می‌گیرند. در اینجا تمرکز بر نوشتن کدهای تمیز، استاندارد و سازگار با اصول دسترسی‌پذیری (Accessibility) است.

---

## مفاهیم و مباحث کلیدی

در این بخش، تمرین‌ها و نمونه‌کارهای مرتبط با موارد زیر قرار می‌گیرد:

1. **مبانی و تگ‌های پایه:**
   - آشنایی با ساختار استاندارد یک سند HTML (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)
   - تگ‌های متنی (سرتیترها از `<h1>` تا `<h6>`، پاراگراف‌ها، نقل‌قول‌ها و متن‌های تاکیدی)
   - لینک‌ها (`<a>`) و تصاویر (`<img>`)

2. **لیست‌ها و جداول:**
   - لیست‌های مرتب (`<ol>`) و نامرتب (`<ul>`)
   - ساخت جدول‌های اطلاعاتی ساختاریافته (`<table>`, `<tr>`, `<th>`, `<td>`)

3. **فرم‌های تعاملی:**
   - دریافت اطلاعات از کاربر با انواع `input`ها (متن، ایمیل، پسورد، تاریخ و...)
   - المان‌های انتخاب مانند `select`، `textarea` و دکمه‌های ارسال (`button`)
   - برچسب‌گذاری صحیح (`<label>`) برای بهبود تجربه کاربری و دسترسی‌پذیری

4. **استانداردهای معنایی (Semantic HTML):**
   - استفاده از تگ‌های مفهومی مدرن مانند `<header>`، `<nav>`، `<main>`، `<section>`، `<article>`، `<aside>` و `<footer>` برای بهبود ساختار سئو (SEO) و خوانایی کد.

---

## نحوه مشاهده فایل‌ها

برای مشاهده هر کدام از فایل‌های HTML این پوشه:
1. روی فایل مورد نظر (مثل `index.html`) کلیک کنید.
2. آن را مستقیماً در یک مرورگر وب (Chrome, Firefox, Edge) رها (Drop) کنید یا باز نمایید.
3. یا از افزونه **Live Server** در ویرایشگر VS Code برای مشاهده زنده تغییرات استفاده کنید.
